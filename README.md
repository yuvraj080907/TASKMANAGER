# TASKMANAGER

A full-stack Task Management Application built with Node.js, Express, MongoDB, Socket.io, and React with Vite and Tailwind CSS.

## Features
- User Authentication (JWT + Password Hashing)
- Real-time updates with Socket.io
- Task CRUD operations with priorities and due dates
- Responsive UI built with React & Tailwind CSS

## Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB (or in-memory server automatic fallback)

### Installation & Setup

1. **Backend**:
   ```bash
   cd backend
   npm install
   npm run dev
   ```

2. **Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
